# LOY KRATHONG 2026 — Premium Krathong Update

เว็บลอยกระทงแบบ mobile-first พร้อมตัวกระทงใบตองทรงชามมีมิติ และดอกไม้ SVG วาดเป็นกลีบ ไม่ใช้ emoji เป็นรูปดอกไม้บนตัวกระทง

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ด้วย VS Code
3. เปิด `index.html` ผ่าน Live Server หรือเปิดด้วย Chrome/Edge

## ไฟล์
- `index.html` โครงสร้างทุกหน้า
- `style.css` รูปแบบ สี แสง เงา และ responsive
- `main.js` การตกแต่งกระทง การครอปรูป การลากลงแม่น้ำ และกระทงเพื่อน

## อัปเดตในรุ่นนี้
- ดอกดาวเรือง มะลิ ชบา บัว และดอกไม้ขาวเป็นภาพ SVG กลีบซ้อน มีไล่เฉดสีและเกสร
- ตัวกระทงเพิ่มชั้นใบตองพับ ขอบปากกระทงแบบซ้อน เงาด้านใน และลายสาน
- เพิ่มมิติและเงาให้ภาพกระทงและของตกแต่ง
- ยังคงระบบแตะเพื่อเพิ่มของตกแต่งลงตำแหน่งที่กำหนดไว้ และนำกระทงแบบเดียวกันไปแสดงในแม่น้ำ

## หมายเหตุเรื่องกระทงเพื่อน
รุ่นนี้เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์ จึงใช้ดูข้อมูลในเบราว์เซอร์เดียวกันได้ก่อน หากต้องการให้เพื่อนคนละเครื่องเห็นกระทงกัน ต้องเชื่อมฐานข้อมูลออนไลน์ เช่น Supabase
